## 🧩 O que vamos construir?

Durante o minicurso, exploraremos os componentes fundamentais de uma aplicação web.

```text
👤 Usuário
   │
   ▼
🌐 Front-end
   HTML + CSS
   │
   ▼
⚙️ Back-end
   PHP
   │
   ▼
🗄️ Banco de dados
   MySQL
```

Cada tecnologia desempenha um papel importante:

- **HTML:** define a estrutura e o conteúdo das páginas.
- **CSS:** controla a apresentação visual e o layout.
- **PHP:** processa informações e executa a lógica no servidor.
- **MySQL:** armazena e organiza os dados da aplicação.

## 🔎 Conceitos importantes

### 📥 GET e POST
Métodos utilizados para enviar informações em requisições HTTP. A escolha depende do objetivo da operação e de como os dados devem ser transmitidos.

### 🔒 Senhas e autenticação
O armazenamento de senhas exige cuidados de segurança. Em PHP, funções como `password_hash()` e `password_verify()` ajudam a implementar o armazenamento seguro e a verificação de senhas.

### 🛡️ Consultas preparadas
Consultas preparadas, como as oferecidas pelo PDO, ajudam a separar os comandos SQL dos valores fornecidos pelo usuário, reduzindo o risco de injeção de SQL quando utilizadas corretamente.

### 🔄 CRUD
CRUD representa as quatro operações básicas de persistência de dados:

| Operação | Significado | Exemplo |
|---|---|---|
| **C — Create** | Criar | Cadastrar um registro |
| **R — Read** | Ler | Listar registros |
| **U — Update** | Atualizar | Editar um registro |
| **D — Delete** | Excluir | Remover um registro |
