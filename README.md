## 👋 Sobre o minicurso

Bem-vindo(a) ao repositório do minicurso **Programação Web com HTML, PHP e MySQL**!

Este espaço reúne os materiais utilizados durante o minicurso, com o objetivo de apresentar os fundamentos do desenvolvimento web e demonstrar como diferentes tecnologias trabalham juntas para construir aplicações dinâmicas.

Ao longo do material, você terá contato com a criação de páginas, o processamento de formulários no servidor e a integração com um banco de dados relacional.

🎯 **Nosso objetivo:** compreender o funcionamento básico de uma aplicação web e construir as primeiras funcionalidades de um sistema completo.
